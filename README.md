# Publikey

## Descrição

**Publikey** é o primeiro projeto acadêmico desenvolvido em colaboração com colegas de turma. Trata-se de um site institucional para uma agência de **gestão de imagem e conteúdo artístico**, com foco na divulgação de influenciadores/talentos representados pela agência e de suas marcas parceiras.

## Objetivo

Aplicar na prática os conhecimentos adquiridos em sala de aula, desenvolvendo em equipe um site institucional completo — do layout ao conteúdo — simulando um projeto real de agência de publicidade.

## Funcionalidades / Seções do site

- **Home**: seção inicial com vídeo de fundo e chamada para ação
- **Sobre**: apresentação da agência e sua missão
- **Influencer**: carrossel com os talentos/influenciadores representados
- **Marcas**: grid com as marcas parceiras
- **Contato**: formulário de contato (pessoa física ou empresa) e links para redes sociais
